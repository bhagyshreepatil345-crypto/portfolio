✅ 1. Discuss the advantages and disadvantages of Cloud

Advantages

  1. Cost Saving

    • No need to buy servers or hardware.

    • Pay-as-you-use reduces capital expenditure.

  2. Scalability

    • Resources (CPU, RAM, storage) can increase or decrease automatically as per demand.

  3. Accessibility

    • Applications and data accessible anytime, anywhere using the internet.

  4. Disaster Recovery

    • Data automatically backed up in multiple locations.

  5. Flexibility

    • Supports multiple devices (mobile, PC, tablet).

    • Easy to deploy new applications.

  6. Automatic Updates

    • Cloud providers manage software updates, patches, security upgrades.

  7. High Performance

    • Uses distributed servers, load balancing, and optimized data centers.

Disadvantages

  1. Internet Dependency

    • Without internet, service becomes unavailable.

  2. Security Concerns

    • Sensitive data stored on a third-party server.

  3. Limited Control

    • Users have less control over hardware and backend.

  4. Downtime Issues

    • Server outages of cloud provider may affect users.

  5. Vendor Lock-in

    • Difficult to migrate data/applications to another provider.

  6. Hidden Costs

    • Extra charges for bandwidth, storage, monitoring, etc.

✅ 4. What is Cloud Computing? Explain Roots of Cloud Computing

Definition

Cloud computing is a technology that provides on-demand access to computing resources (servers, storage, applications) over the internet.

Roots (Origin)

  1. Grid Computing – distributed computing for solving large problems.

  2. Utility Computing – electricity-like pay-per-use model.

  3. Virtualization Technology – running multiple VMs on one machine.

  4. Web 2.0 / Internet services – Google, Amazon, social media apps.

  5. Data center automation – scalable server farms.

✅ 5. Write a note on SaaS & PaaS

SaaS (Software as a Service)

  • Complete software delivered via internet.

  • No installation required.

  • Example: Gmail, Google Docs, Salesforce.

Features

  • Subscription model

  • Automatic updates

  • Accessible from browser

PaaS (Platform as a Service)

  • Provides platform for application development.

  • Includes OS, runtime, database, tools.

Examples

  • Google App Engine

  • Microsoft Azure App Services

Features

  • Developers focus only on coding

  • Scalable runtime environment

  • Supports multiple languages/frameworks

✅ 6. What are the different types of Cloud?

  1. Public Cloud – AWS, Azure, Google Cloud.

  2. Private Cloud – used by a single organization (OpenStack).

  3. Hybrid Cloud – combination of public + private.

  4. Community Cloud – shared by organizations with similar needs.

✅ 7. What is Virtual Machine Migration?

VM migration is the process of moving a running virtual machine (its OS, apps, storage) from one physical host to another.

Types

  1. Cold Migration – VM stopped, then moved.

  2. Live Migration – VM moved while running (no downtime).

  3. Warm Migration – VM moved during reboot.

Uses

  • Load balancing

  • Hardware maintenance

  • Fault tolerance

  • Energy saving

✅ 8. What is Hypervisor? Explain in detail

A hypervisor is a software layer that allows multiple virtual machines to run on one physical machine.

Types

  1. Type 1 (Bare Metal)

    • Runs directly on hardware

    • Examples: VMware ESXi, Hyper-V, Xen

  2. Type 2 (Hosted)

    • Runs on top of OS

    • Examples: VMware Workstation, VirtualBox

Functions

  • VM creation

  • Resource allocation

  • Isolation of VMs

  • Performance monitoring

  • Hardware emulation
